# Poker Goblins

WIP. This will be a React web app for playing poker online, with paper money. Built using Vite and pnpm. Styled by Mantine UI.
The backend will use Apollo/GraphQL and MongoDB.

Additional pages will be built for
a) a sandbox mode, where odds in differnent positions can be calculaed, and specific hands can be replayed
b) a VPIP calculator, where you can mark each hand based on typical pre flop behaviour

Check out the changelog for a current history of changes made.
